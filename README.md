# ejercicio01

## Proposito del proyecto 
Este proyecto permite calcular el porcentaje de propina a partir de un monto ingresado por el usuario, mostrando tambien el total a pagar.

## Tecnologías utilizadas
java
github
jira

## Instrucciones de uso
1. ejecuta el script `calculadora.py`
2. Ingresa el monto total de la cuenta
3. Elige el porcentaje de propina deseado (10%, 15%, 20%)
4. se mostrara el valor de la propina y el total a pagar
